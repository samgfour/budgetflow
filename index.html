BudgetFlow

BudgetFlow is a simple Python budgeting tool that helps you split a monthly income using the 15/20/30/35 allocation rule: investing, savings, pay-yourself, and expenses.

What it does

Calculates how much of your monthly income goes to each category and shows the total allocation.

Where the logic lives

The main script is budgetflow.py, which contains the income input, calculation, and CLI output.

Why it matters

It turns a broad money rule into a quick, easy-to-use budget breakdown you can run from the terminal.
